# Student Planner app

The frontend is in `src/`. The Express API is in `backend/server.js`, with MongoDB access and account storage in `backend/data/store.js`.

The recommended commands are run from the repository root: `npm run dev`, `npm run build`, and `npm run preview`. The app uses `client--/.env` for `MONGODB_URI` and `MONGODB_DB`. Compass/presentation setup is documented in `database/README.md`.
